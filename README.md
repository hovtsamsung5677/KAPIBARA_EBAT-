# Ферма капибар

Idle/clicker игра для платформы Яндекс Игры.

## Сборка ZIP

Сжать содержимое папки `yandex-capybara-farm/` так, чтобы `index.html` был в корне архива.

## Локальный запуск

```bash
npx serve .
```

или

```bash
python -m http.server 3000
```

Открыть в браузере. Для отладки SDK добавить `?debug-mode=16`.

## Загрузка в Яндекс Игры

1. Создать черновик в Консоли разработчика Яндекс Игр.
2. Загрузить ZIP-архив.
3. Заполнить метаданные игры.
4. Отправить на модерацию (3–5 рабочих дней).

## Монетизация

В Консоли разработчика → вкладка «Реклама» → включить:
- Fullscreen adv
- Rewarded video
- Sticky banner

## Лидерборд

В Консоли разработчика → вкладка «Лидерборды» → создать лидерборд с идентификатором `capybara_farm_score` (тип: числовой, выше = лучше). Без этого шага кнопка рейтинга будет работать, но данные не будут сохраняться на сервере.
